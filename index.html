ギャクサン - 就活の逆算カレンダー

就活の締切を入れると、そこから逆算して今日やることが並ぶカレンダーアプリです。適性検査の練習も、受検日から逆算して毎日の分だけ出します。

お問い合わせ

ご質問・不具合のご報告は GitHub Issues からお送りください。お使いの端末とiOSのバージョン、起きたことをお書きいただけると助かります。

よくある質問

購入したのに使えない／機種変更した
「記録」タブ右上の歯車（設定）→「購入を復元」を押してください。同じApple Accountで購入した場合に復元されます。

データはどこに保存されますか
登録した企業・締切・練習の記録は、すべてお使いの端末の中だけに保存されます。会員登録やサーバーへの保存はありません。設定から JSON で書き出せます。

締切の通知が来ない
iOSの「設定」→「通知」→「ギャクサン」で通知が許可されているかご確認ください。
